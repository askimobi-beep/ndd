# Portal Frontend

A React application with Tailwind CSS and routing.

## Installation

1. Navigate to the project directory: `cd portal-frontend`

2. Install dependencies: `npm install`

## Running the Application

Run `npm start` to start the development server.

The app will be available at http://localhost:3000

## Features

- Sidebar navigation that expands on hover
- Routing for Account, Dashboard, Fuel Tax, and Contact Us pages
- Tailwind CSS for styling
